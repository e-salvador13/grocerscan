Lessons

Challenges & Lessons Learned

⚠️ Challenge: Walmart Blocks Scraping
Pivoted to published price surveys, BLS CPI data, and Kroger API — multiple data sources reduce single-point-of-failure risk.
⚠️ Challenge: OCR on Faded / Low-Quality Receipts
Added image preprocessing (contrast, threshold) and Claude Vision AI as an intelligent fallback for difficult receipts.
⚠️ Challenge: Receipt Abbreviations
Built a 150+ abbreviation mapping table (e.g., "GV WHL MLK" → "Great Value Whole Milk") for reliable product matching.
💡 Key Lesson
Risk mitigation through redundancy — multiple data sources and fallback pipelines ensure the system is resilient.
